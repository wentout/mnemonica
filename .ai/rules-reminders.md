# Quick Check Before Coding

## Type vs Interface
See [rules-type-system.md](./rules-type-system.md#type-vs-interface-rule).

## Indentation
Tabs only. Width 4. See [rules-code-style.md](./rules-code-style.md).

## Function Spacing
Space before paren: `function myFunc ()`. See [rules-code-style.md](./rules-code-style.md).

## Key Spacing
Space after colon: `{ key : value }`. See [rules-code-style.md](./rules-code-style.md).

## Before Each Task
1. Read AGENTS.md if context seems incomplete
2. Check existing code patterns in the same directory
3. Run `npm run build` before completing
4. Run `npm run test:cov` for coverage validation
