# Quick Check Before Coding

## Type vs Interface
See [type-system.md](../rules-skill/type-system.md#type-vs-interface-rule).

## Indentation
Tabs only. Width 4. See [code-style.md](../rules-skill/code-style.md).

## Function Spacing
Space before paren: `function myFunc ()`. See [code-style.md](../rules-skill/code-style.md).

## Key Spacing
Space after colon: `{ key: value }`. See [code-style.md](../rules-skill/code-style.md).

## Before Each Task
1. Read AGENTS.md if context seems incomplete
2. Check existing code patterns in the same directory
3. Run `npm run build` before completing
4. Run `npm run test:cov` for coverage validation
